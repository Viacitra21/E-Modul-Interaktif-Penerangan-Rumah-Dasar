Folder ini untuk foto asli komponen/trainer kalau kamu mau menggantikan
ilustrasi SVG bawaan di halaman Materi (tab Komponen & Kenali Simbol).

Cara pakai:
1. Taruh foto di sini, misal: assets/img/mcb.jpg
2. Di materi.html, cari kartu komponen terkait, lalu ganti tag <svg>...</svg>
   dengan: <img src="assets/img/mcb.jpg" alt="MCB">
