# Jobsheet PDF

Simpan dua file PDF jobsheet di folder ini dengan nama PERSIS:

    jobsheet-1-proteus.pdf     -> Jobsheet 1: Simulasi menggunakan Proteus
    jobsheet-2-trainer.pdf     -> Jobsheet 2: Praktikum menggunakan Trainer

Begitu file ada (lalu di-push ke GitHub), halaman **Praktik** otomatis menampilkan
PDF-nya + tombol "Buka di tab baru" dan "Unduh PDF". Di HP, PDF dibuka lewat tombol
(karena browser HP tidak bisa menampilkan PDF di dalam halaman).

Tips: kompres PDF jika lebih dari ±20 MB (mis. lewat smallpdf / ilovepdf) agar cepat dibuka siswa.
